sizing signal: the single-process loopback bench cannot sustain 100+
destinations (each send_shared admits per-destination sender-window state
and each submitted DATA needs loopback RX + ACK processing in the same
process). Lane QD cannot be selected from this bench. Decision: keep
DEFAULT_TX_POOL_CAPACITY=256 (bounded, independent of fanout) and build
the real two-process qualification harness where Q << F can be measured
without loopback collapse.
